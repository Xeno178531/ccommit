### Linux / macOS
Otwórz terminal i uruchom:
```bash
curl -sSL https://raw.githubusercontent.com/xeno178531/ccommit/main/install.sh | bash
```

### Windows
Uruchum powershell jakod administrator
```ps1
irm https://raw.githubusercontent.com/xeno178531/ccommit/main/install.ps1 | iex
```

### Użycie
W terminalu / powershellu użyj `ccommit`
